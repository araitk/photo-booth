# Photo Booth

ブラウザ内で動作するPhoto Booth。TypeScript・HTML/CSS・Viteで実装しています。

## 開発

```sh
pnpm install
pnpm dev
```

表示されたlocalhostのURLをブラウザで開きます。カメラの使用許可が必要です。音声の取得や画像の外部送信は行いません。

タイマーと解像度はブラウザのlocalStorageに保存し、次回起動時に復元します。解像度は実際に適用できた設定を記憶します。保存データが不正・保存機能が利用できない場合は標準設定で動作します。

上部の「カメラ」で内蔵・外付けカメラを選択できます。カメラの許可後に名前と一覧を更新し、接続・取り外しにも追従します。撮影・写真表示中は切り替えを無効化し、切り替えに失敗した場合は利用可能な元のカメラへ戻ります。

```sh
pnpm build
```

型チェックと配布用のビルドを実行します。CSSとJavaScriptをすべて含む単一ファイル `dist/photo-booth.html` を生成します。このファイルをブラウザで直接開けます。ルートの `index.html` は開発用なので、直接開く場合は必ずビルド後のファイルを使ってください。

ローカルファイルのカメラ利用はブラウザの許可・対応状況によって異なります。利用できない場合はlocalhostから開いてください。

## 第1段階

- ミニマルな画面とレスポンシブレイアウト
- カメラの開始、プレビューだけの左右反転
- 解像度選択は上部、撮影ボタンと写真一覧はプレビュー内に配置
- プレビュー左上にOFF・CONNECTING・LIVEなどのカメラ状態を表示し、その下に実際の映像サイズとfpsを表示
- プレビューだけのフルスクリーン表示。プレビュー右上のボタンまたはEscで終了
- 常時表示の3×3グリッド
- 自動・720p・1080p・4Kの解像度選択
- 実際の映像サイズと設定fpsの表示
- 未対応の解像度から元の設定への復帰
- 権限拒否・カメラ未接続などの案内

## 第2段階

- カメラの準備ができたら撮影ボタンを有効化
- 実際の映像サイズでPNGを生成。左右反転・グリッド・操作部は含めない
- 撮影直後にPHOTO表示へ切り替え、3秒後または写真のクリックでカメラへ戻る
- 戻る演出は1秒で縮小して下へ移動
- 短い撮影フラッシュ。OSの視差効果を減らす設定では演出を省略
- 再撮影はカメラ映像に戻った後に有効化
- 写真表示終了時に表示用の画像URLを解放

## 第3段階

- PNG原本と幅240px以下・品質0.8のJPEGサムネイルを保持
- プレビュー下部に写真を右詰めで並べ、右端から新しい順に表示。横スクロール可能
- 1秒の縮小演出で右端へ移動し、演出終了後にサムネイルを追加。枚数は撮影時に更新
- サムネイルから開いた写真はクリックまたは戻るボタンまで表示
- 選択中の写真をPNGでダウンロード、または削除
- 削除時に原本への参照・サムネイルURL・表示用URLを解放
- フルサイズ画像は選択中の1枚だけ表示

## 第4段階

- 上部の解像度の左でタイマーを選択（なし・3秒・5秒・10秒）
- 中央に残り秒数を表示し、終了時に1枚撮影
- カウント中は撮影ボタンがキャンセルボタンに変わり、Escでも中止可能
- カウント中は設定変更と写真選択を無効化
- カメラ切断・ページを離れる・別のタブに移動するとカウントを中止

`pnpm test` で画像の保持・削除、ファイル名、演出の移動先、カウントダウンとキャンセルを検証します。Node.js 24以上を使用してください。

## ショートカット

| キー | 操作 |
| --- | --- |
| Space | 撮影、プレビュー中は閉じる、タイマー撮影中はキャンセル |
| Esc | タイマー撮影をキャンセル、写真プレビューを閉じる |
| ← / → | プレビュー中は隣の写真へ切り替え（端では停止）。カメラ中は←で最新、→で最古を表示 |
| S | 選択中の写真をPNGで保存 |
| F | フルスクリーンを切り替え |
| Delete / Backspace | 選択中の写真を削除（MacではDeleteキー単独） |
| Enter | カメラ開始前にカメラを開始 |
| ? | ショートカット一覧を表示／閉じる |
| ⌘Z / Ctrl+Z | 直前の1枚の削除を取り消す |

左右矢印は長押しで移動できます。削除後は右隣の新しい写真を選択し、なければ左隣の古い写真、全件削除後はカメラへ戻ります。

選択中のサムネイルは見える位置まで自動スクロールします。削除後の「元に戻す」ボタンまたは⌘Z / Ctrl+Zで、直前に削除した1枚を元の位置へ戻して選択できます。次の削除で履歴が置き換わり、ページを閉じる・再読み込みすると消えます。取り消し用には原本とサムネイルを1枚分だけ保持します。

全画面中のEscはブラウザ標準の全画面終了を優先します。設定の選択・文字入力中、左右矢印以外のキーの長押し、Ctrl・⌘・Altとの組み合わせではショートカットを実行しません。カメラ表示中にボタンへフォーカスしている場合、Spaceはそのボタンの通常操作を優先します。写真プレビュー中はSpaceでプレビューを閉じます。

## 連続撮影・メモリ管理の確認

- canvasの画像生成とDOMを模した自動テストで、100回の撮影・表示・復帰・削除を検証
- 保持する原本・サムネイル画像・URLの数が写真枚数と取り消し用の1枚に対応し、履歴を含めてクリアした後に残らないことを確認
- ダウンロード用URLの削除時の解放と、撮影用canvasのサイズを処理終了時に0へ戻すことを確認
- PNG生成中の切断・再接続・再撮影を再現し、撮影ごとに独立したcanvasを使うことで古い処理の干渉を防止
- このテストは参照とURLの管理を検証するもので、実カメラやブラウザ全体のメモリ使用量の計測ではない

## 確認項目

### 実ブラウザでの確認（2026-10-02）

- アプリ内ブラウザで実カメラ（1920×1080 / 30fps）による計4枚の撮影、3秒タイマー、10秒タイマーのキャンセル、写真の再表示を確認
- サムネイル4枚の読み込み完了と、右端から新しい順の配置を確認
- 写真の表示サイズが1920×1080で、ミラー変換がプレビューにだけ適用されることを確認
- PNGのダウンロードを確認。保存ファイルはPNG形式・1920×1080・3,366,208バイト
- アプリ内ブラウザでプレビューだけの全画面表示と解除を確認
- Chromeの幅390pxでは横のはみ出しがなく、プレビューの16:9を維持
- 高さ360pxで撮影ボタンが画面外へ出る問題を修正。640×360でプレビュー・撮影・全画面ボタンが画面内に収まることを確認
- 配布HTMLに外部アセットの参照がないことをファイルから確認
- 未確認：Safari、Chromeでの撮影、実ブラウザの削除操作とメモリ使用量。Chromeでは今回カメラの開始が接続中のままで、全画面への切り替えも失敗したため成功扱いにしていない
- HTMLの直接起動は操作ツールが `file://` を拒否するため未確認。外部アセットの参照確認だけでは直接起動時の動作を保証しない
- 上記の未確認項目は、その後ユーザーから確認済みとの報告あり（エージェントによる実測・再検証は行っていない）

1. カメラを開始し、映像がミラー表示されていることを確認する。
2. グリッドが常に表示され、映像全体を三分割していることを確認する。
3. 解像度を切り替え、実際の映像サイズの表示が変わることを確認する。
4. 未対応の解像度を指定した場合、設定が戻り案内が表示されることを確認する。
5. ページを閉じるとカメラが解放されることを確認する。
6. フルスクリーンの開始・終了と、操作部や写真一覧が表示されることを確認する。
7. 撮影後の写真が本来の向きで、実際のカメラ映像と同じ解像度になっていることを確認する。
8. 1秒の縮小演出で戻ることを、クリック復帰と3秒後の自動復帰でそれぞれ確認する。
9. 複数枚を撮影し、写真の選択・PNGダウンロード・削除と、全件削除後の表示を確認する。
10. なし・3秒・5秒・10秒の撮影と、カウント中のボタン・Escによるキャンセルを確認する。
11. 選択したタイマーがフルスクリーンでも働き、カメラ切断やタブ移動でカウントが中止されることを確認する。
